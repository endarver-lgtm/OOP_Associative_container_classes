# Лабораторная работа №4: Ассоциативные контейнеры STL

## Описание проекта
Проект представляет собой программный комплекс для глубокого изучения и практического освоения всех 8 ассоциативных контейнеров стандартной библиотеки шаблонов (STL) C++. В качестве прикладной области реализована автоматизированная информационная система учета и диспетчеризации строительной техники компании (Вариант 10). Система обеспечивает учет техники, объектов строительства, тарифных сеток, наработки оборудования и графиков смен.

## Цели и задачи работы
- Изучение принципов организации и функционирования упорядоченных ассоциативных контейнеров на основе красно-черных деревьев поиска: `std::map`, `std::set`, `std::multimap`, `std::multiset`.
- Освоение неупорядоченных ассоциативных контейнеров на основе хеш-таблиц: `std::unordered_map`, `std::unordered_set`, `std::unordered_multimap`, `std::unordered_multiset`.
- Сравнительный анализ временной сложности базовых операций (вставка, поиск, удаление): логарифмическая O(log N) для деревьев против константной O(1) в среднем для хеш-таблиц.
- Практическое применение специализированных алгоритмов поиска в диапазонах с повторяющимися ключами: `equal_range()`, `lower_bound()`, `upper_bound()`, `count()`.
- Организация синхронного обновления данных в нескольких взаимосвязанных контейнерах при операциях добавления, модификации и удаления.

## Предметная область: Учет строительной техники (Вариант 10)
Система диспетчеризации решает задачи комплексного производственного учета:
- Ведение центрального реестра техники с подробными реквизитами.
- Контроль перечня действующих строительных площадок и распределения техники по объектам.
- Анализ тарифной сетки аренды и подбор техники в заданных ценовых интервалах.
- Накопительный мониторинг отработанных моточасов по каждому государственному регистрационному номеру.
- Классификация категорий выполняемых технологических операций и учет продолжительности смен.

## Архитектура и используемые контейнеры STL

### Базовая модель данных (`EquipmentRecord`)
Класс инкапсулирует полную запись об единице строительной техники:
- Уникальный системный идентификатор (ID).
- Модель техники (например, Caterpillar 320D, Komatsu PC210, JCB JS220).
- Государственный регистрационный знак.
- Наименование строительного объекта базирования.
- Почасовая тарифная ставка (руб/час).
- Суммарно отработанное время (в моточасах).
- Технологическая категория работ (земляные, монтажные, погрузочные).

### Менеджер ассоциативных структур (`AssociativeManager`)
Центральный класс, объединяющий и синхронизирующий 8 специализированных контейнеров STL:

1. `std::map<int, EquipmentRecord> equipmentMap_`
   - Главный упорядоченный реестр парка техники с быстрым доступом по целочисленному уникальному ID. Обеспечивает быстрый поиск, редактирование реквизитов и удаление записей за O(log N).

2. `std::set<std::string> sitesSet_`
   - Упорядоченное множество уникальных наименований строительных площадок. Исключает дублирование объектов и автоматически поддерживает их в алфавитном порядке.

3. `std::multimap<std::string, EquipmentRecord> siteAssignments_`
   - Упорядоченное отображение с множественными значениями: связывает название строительного объекта с работающими на нем единицами техники (отношение "один объект - много машин").

4. `std::multiset<double> ratesMultiset_`
   - Упорядоченная мультимножественная тарифная сетка почасовых арендных ставок. Допускает одинаковые тарифы для разных машин. Используется для демонстрации алгоритмов диапазонного поиска.

5. `std::unordered_map<std::string, int> hoursByRegNumber_`
   - Неупорядоченная хеш-таблица для быстрого получения и инкремента наработки моточасов по регистрационному номеру машины. Время выборки и обновления стремится к O(1).

6. `std::unordered_set<std::string> workCategories_`
   - Неупорядоченное хеш-множество уникальных категорий выполняемых работ без сохранения порядка вставки.

7. `std::unordered_multimap<std::string, std::string> modelsToRegNumbers_`
   - Неупорядоченная хеш-таблица соответствия названий моделей их регистрационным номерам (позволяет быстро находить все машины конкретной модели в парке).

8. `std::unordered_multiset<int> shiftDurations_`
   - Неупорядоченная хеш-структура с повторениями, регистрирующая длительность отработанных смен для последующего статистического анализа.

## Функциональные возможности программы
- Полный жизненный цикл записей (CRUD): добавление новой техники с каскадным обновлением всех 8 структур данных; безопасное удаление по ID с очисткой зависимостей; редактирование тарифов, часов и локаций.
- Алгоритмы диапазонного поиска STL: демонстрация работы функций `count()`, `equal_range()`, `lower_bound()` и `upper_bound()` на контейнере `multiset` для поиска машин с тарифами в заданных границах.
- Поиск и фильтрация: регистронезависимый поиск по подстроке модели или номера; фильтрация карточек по технологической категории.
- Диспетчеризация по объектам: выборка всей техники, закрепленной за конкретной стройплощадкой, через `equal_range()` в `std::multimap`.
- Инспекция и экспорт: вывод содержимого любого контейнера на экран в форматированном табличном виде; полный экспорт всех 8 структур в текстовый отчет.
- Надежный консольный интерфейс: защита от некорректного ввода числовых значений и переполнений (модуль `Input.h`), поддержка кодировки Windows-1251.
